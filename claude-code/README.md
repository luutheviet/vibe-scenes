# vibe-scenes (Claude Code)

Plugin Claude Code vẽ hình nền động phong cách Việt Nam phủ kín cửa sổ, kèm bảng màu riêng cho từng cảnh, trong tab Code của app Claude Desktop và app điện thoại. Gõ `/scene` để mở bảng chọn, `/scene bien-dem`, `/scene ruong`, `/scene den-long`, `/scene tre` để đổi cảnh, `/scene off` để tắt. Không gọi mạng, không chạy lệnh, không đọc file hay hội thoại.

Cài đặt, cách tự tạo cảnh và giấy phép: xem [README chính](../README.md).

```
/plugin install vibe-scenes --marketplace luutheviet/vibe-scenes
```
